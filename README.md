# POV CUT

**その目線を、2.5秒ずつ。**

Rokid Glassesなどのカメラ付きスマートグラスで撮った動画を、2.5秒ずつつないでVlogにする日本語のWebアプリです。動画はブラウザ内で編集し、サーバーへアップロードしません。

**[アプリを開く](https://aym-same.github.io/pov-cut/)** · [不具合・改善提案](https://github.com/aym-same/pov-cut/issues)

GitHub Pagesの無料枠で公開しています。有料APIや専用サーバーは使用しません。

## できること

- 各動画から2.5秒を切り出す／動画全体を2.5秒ずつ分割
- 縦型9:16・横型16:9、720p・1080p、MP4・WebMの書き出し
- クリップごとの中央テキストと、全体のハッシュタグ
- フォント・文字サイズ・色の選択、文字スタイルの一括適用
- フェード・ブラックアウト・ホワイトフラッシュ、切り替え効果の一括適用
- 切り抜き位置の上下・左右調整、全体を収める表示
- 元音声のオン／オフ、プレビュー、並べ替え、編集の取り消し
- 編集内容の自動保存、JSONへの保存と再開

## 起動する

Node.js 24を推奨します（22.13以上）。APIキーやアカウント登録は不要です。

```sh
npm ci
npm run dev
```

表示されたlocalhostのURLをChromeまたはEdgeで開きます。

```sh
npm run lint
npm test
npm run build
npm run preview
```

本番用のファイルは`dist/`に生成され、HTTPSの静的ホスティングで配信できます。GitHub Pagesのサブディレクトリで配信する場合は`BASE_PATH=/pov-cut/`を指定してビルドしてください。実装は[Viteの静的配信手順](https://vite.dev/guide/static-deploy.html#github-pages)に沿っています。

このリポジトリでは`main`へのpush後、GitHub Actionsがlint・テスト・ビルドを実行し、成功した場合にGitHub Pagesへ公開します。forkして公開する場合は、リポジトリのSettings → Pages → Sourceを「GitHub Actions」に設定してください。標準の`ユーザー名.github.io/リポジトリ名/`形式を想定しています。

## 使い方

1. 動画を追加し、タイムラインから編集するクリップを選ぶ。
2. 切り出し開始位置、画面の切り抜き、中央の文字を調整する。
3. 縦横比、ハッシュタグ、切り替え効果を設定する。
4. プレビューを確認し、「書き出す」→「動画を保存」でダウンロードする。
5. 続きを編集するときは「前回の編集を再開」または「編集を開く」を使い、元動画を選び直す。

## 保存とプライバシー

動画本体は送信・永続保存しません。ブラウザの自動保存と編集JSONには、編集内容に加えて元動画のファイル名・容量・更新日時が含まれます。再開時には、同じ名前と容量の元動画を端末から選択してください。JSONを他の人へ渡す場合はファイル名にもご注意ください。

自動保存はブラウザ・サイトURLごとに1件です。別ブラウザや別サイトへ編集を移す場合はJSONを使います。プライベートブラウズや容量制限で自動保存できない場合は、JSONを保存してください。

## 対応と制限

- WebCodecsに対応したChrome / Edgeを推奨。動画形式や音声コーデックの対応は端末・ブラウザに依存します。
- 1クリップ2.5秒・30fps。最大60クリップ（150秒）、素材30本、1本2GBまで。実際に扱える大きさは端末のメモリに依存します。
- 短い動画は最後のフレームを保持し、足りない音声は無音になります。
- MP4はH.264/AAC、WebMはVP9/Opusです。音声付きMP4に非対応の場合はWebMか無音で書き出してください。
- SNSへの直接投稿、BGMの追加、クラウド保存は含みません。
- Safari/iPhoneや各スマートグラス実機の全形式での動作は保証していません。
